使用说明

输入与规则

每个输入数字恰好使用一次。默认按输入顺序计算；“可变顺序”允许重新排列。选择数字范围、随机一组都不会改变目标值；目标留空可查看结果分布。

数字支持整串输入（空格或逗号分隔）和分格编辑；输入框右侧箭头可选择 1～4 至 1～12。随机一组生成 3～9 个 1～9 的整数，不保证有解。“逆序”反转当前数字的排列，再点一次恢复；不改变目标值，也不自动计算。

“数字连接”允许相邻数字连接。“最多连接两位数”只限制连接后的书写位数，不限制原本输入的多位数；未开启连接时不可选择。

“首数取负”允许第一个数字或连接块取负；“整体取负”允许整个算式外加一次负号；“反向减法”允许任意子式使用 −x+y。这些都是额外允许，不要求每条算式都使用。

合并重复

开启后，保存的算式和“只统计数量”都按去重后的条数计算；关闭后保留原始写法。“合并重复”按运算结构合并，绝不是把所有数值相同的算式合成一个。保留每个输入数字及其运算步骤，不消去乘 1、除 1、加 0，也不使用分配律、约分或因式分解。

  • 固定顺序时合并结合写法：a+(b+c) 与 (a+b)+c；a−(b−c) 与 a−b+c；a÷(b÷c) 与 a÷b×c（分母均须非零）。
  • 同时开启“可变顺序”和“合并重复”时，还合并加法项、乘除因子的交换，以及符号移位：a+b 与 b+a；(a−b)×(c−d) 与 (b−a)×(d−c)。相同的输入数字不区分身份。
  • 1+2+3 与 1×2×3 虽然都等于 6，但运算结构不同，仍分别保留。
  • 输入 1、1、11、13 时，1×11+1×13 与 1×13+1×11 会合并；(11÷1+13)÷1 与 (13÷1+11)÷1 不合并，因为内部除以 1 的位置不同。

简化括号

只改变算式显示，不改变计数；选择“只统计数量”时置灰。关闭合并重复时，不同括号结构可能显示成同一个简化算式，但仍各算一条。

保存上限与统计

  • 1 千条／1 万条：找到足够的结果即停止；开启“合并重复”时，上限指去重后的条数，可能还有更多结果。
  • 全部：尝试保存完整结果；规模过大时会明确提示停止，不会将未完成输出标为完整结果。
  • 只统计数量：不保存结果文本。勾选“合并重复”统计去重后的数量，不勾选统计原始数量。去重计数仍需搜索和保存去重依据，可能耗时、占用较多内存，并不保证很快。

目标留空时，统计所有非负整数结果的原始运算树次数，不受“合并重复”和“保存上限”影响。计算过程中可随时停止。

结果过多时

不合并重复且选择“全部”时，在可预先取得完整计数的情况下，原始算式超过 1000 万条会在生成文本前停止。网页文本保存预算为 384 MiB；达到预算会丢弃未完成输出，并提供保存 1000／10000 条或只统计数量的选项。

预算不是所有设备的内存保证；搜索和去重本身也可能耗尽内存，统计还可能超出计数范围。内存较小的设备建议选择有限输出。

查看结果

每页最多 100 条，单页时隐藏分页栏，可在算式区域上下滚动；超过一页时显示翻页和页码跳转。长算式可左右滚动。

顺序与耗时

可变顺序的结果先按数字出现顺序、再按文本排序；有限输出只排序已找到的结果，不保证是全体结果中字典序最前的若干条。

计算与整理用时包含计算、传回、拆分和排序，不包含页面绘制。程序完全离线运行，数据不上传。复制、导出包含本次保存的结果，或本次完整计数。
