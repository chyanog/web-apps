数字规则与自定义

自定义模式只接受数字，可含空格或逗号。有限数字串会反复使用；例如输入 π 的部分数字，也只是重复这段有限串，并不是继续计算 π。

默认取分数小数点后的数字，保留开头的 0；负分数按绝对值取数。有限小数后面补 0。“仅重复循环节”跳过不循环部分，有限小数和无理数均不使用此模式。无理数可直接在主界面输入或点预设按钮。

“全部倒序／升序／降序”处理的是跳过开头位数后、当前图案所取的全部数字。此时循环节起点标记会停用，改变取样位数也可能改变图案。

形状与数字样式

间隙使用格宽百分比，预览与导出比例一致。圆角只作用于方形。数字随格子一起缩放，密集网格可用高清导出查看。

长除法探秘

每一步把余数乘 10，再除以分母，得到下一位数字。出现相同余数后，之后的计算就会重复；余数为 0 时，小数终止。

课堂探索与使用说明

分数与常见无理数

输入 pi（或 π）、e、sqrt(2)（或 √2）、sqrt(3)、sqrt(5)、sqrt(7)、phi（或 φ）。每种常数内置 80,000 位已核验的小数，只依次取这些数字，不把末尾接回开头。它们没有循环节，显示的省略号表示后面还有数字，≈ 表示这里只展示有限位数。φ 是 (1+√5)/2。

从课本示例开始

选择 1/27、10×10，打开数字与路径，观察 0、3、7 如何组成图案。再试 1/13、1/17、1/19，比较循环节长度。

方格的三个子视图

选择“方格”后，可在“单幅”“顺逆对照”和“布匹平铺”之间切换。

中心向外螺旋可为正方形指定首步方向。长方形采用连续路径，首步自动确定。其余排列可选择起始角落。同心方环的每一环都从所选角落开始。

“顺逆对照”保持数字和颜色相同，比较两种旋向；对称轴由起点和起步约定决定，程序会根据实际路径说明。此视图适用于螺旋与方环。

“布匹平铺”重复同一块图案，可选择交替镜像。重复排列并不保证拼接边缘在视觉上自然连续，可以调整数字、大小和配色寻找更协调的接缝。

环形连线

0–9 各占一个扇区。按顺序给每次出现分配圆周位置，并用起止两位的颜色绘制渐变连线。取样 N 位会得到 N−1 条连线。默认从小数点后取数，勾选“含整数位”后，跳过位数从整数部分的第一位计起。“π 示例”使用含整数位的 1,200 位圆周率。

快速展示与慢速讲解

在「重播设置」中可分别选择数值与排列、视图切换、配色与样式变化是否触发快速展示。画板下方可从头重播、播放、暂停、拖动进度、单步演示或直接完成。播放速度适用于自动展开、手动重播和演示。「随机作品」在当前视图中搭配数值、配色和图案参数。

设置与导出

浏览器允许本地存储时，页面会记住上次有效设置。再次用同一浏览器打开同一文件时可以接着调整。点击“恢复默认”可重新开始。

桌面端的导出按钮在右栏底部，窄屏时在画板下方。PNG 与 SVG 导出当前视图的完整图案，包括环形连线。导出采用全部数位和常规配色。作业纸使用单幅方格设置。

所有内容内置，计算在本地进行。分子、分母各最多 80 位；循环节最多检测 100000 位，超过时不声称已识别完整循环节。7 个常见无理数各内置 80,000 位小数，并用整数上下界核验。每边 1–250 格。窄屏用上方按钮切换图案与设置。
